# Modules Log

Pin 日志模块，提供统一的业务日志管理能力。

## 日志类型

模块提供以下日志类型：

- [操作日志](https://ipiner.cn/packages/log/operation)：记录用户对业务资源的操作行为。
- [行为日志](https://ipiner.cn/packages/log/activity)：记录用户或系统产生的业务行为事件。
- [登录日志](https://ipiner.cn/packages/log/login)：记录用户登录事件。
